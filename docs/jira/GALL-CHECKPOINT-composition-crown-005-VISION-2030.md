Consider an enterprise incident class that initially requires:

- expert diagnosis;
- multiple model calls;
- topology search;
- remediation planning;
- risk review.

- deterministic admission;
- compiled policy selection;
- bounded execution by the authorized downstream runtime;
- independent verification.

The “AI” did not merely get faster.

# Delegation/admission wire schemas

- `delegation-admission-artifact-v1.schema.json` — one exact-subject court input.
- `delegation-admission-batch-v1.schema.json` — ggen marketplace projection transport.
- `delegation-admission-history-v1.schema.json` — ordered evidence/delegation snapshots.

These schemas describe transport shape only. Semantic admission remains the executable
court: schema validity does not imply PASS, authority, or standing.
